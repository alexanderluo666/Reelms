# Reelms
This is Reelms, a universe consisting of multiple projects using C++, Raylib.
This will be where the games come from: Reelms:Riftfall, Reelms:Fishing.
It started as a simple idea of a fishing game, now extended to a full universe containing the same vibe and settings.

Currently doing C++ and raylib development for 2D in riftfall, doing WASM and 3D later on with riftfall.
